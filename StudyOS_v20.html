// MONTHLY ROADMAP — MAY TO DECEMBER 2026
8-Month Study Plan
May 2026
PHASE 1 · ENGINEERING MATHEMATICS
Week 1 · May 1–7
Propositional Logic Predicate Logic
Truth tables, logical equivalences, tautologies, quantifiers, inference rules, first-order logic. GATE PYQs: logic problems (2018–2023).
Week 2 · May 8–14
Set Theory Relations & Functions Graph Theory
Sets, power sets, Cartesian product, relations (reflexive, symmetric, transitive), partial orders, Hasse diagrams, functions, graph types (Euler, Hamiltonian, Planar).
Week 3 · May 15–21
Linear Algebra
Matrices, determinants, rank, null space, column space, system of linear equations (Gaussian elimination), eigenvalues & eigenvectors, Cayley-Hamilton theorem.
Week 4 · May 22–31
Probability Statistics Combinatorics
Conditional probability, Bayes' theorem, random variables, expectation/variance, Poisson/Binomial/Normal distributions, counting (permutations, combinations, Pigeonhole principle, inclusion-exclusion).
🎯 May Target: Engineering Maths complete · 60+ PYQs solved · Formula sheet made
June 2026
PHASE 2 · DATA STRUCTURES & ALGORITHMS
Week 1 · Jun 1–7
Linear DS Trees
Arrays, Stacks, Queues, Linked Lists (single/double/circular). Binary Trees, BST (insertion, deletion, traversals), AVL Trees (rotations), Red-Black Trees overview, Heaps (min/max, heapify, heap sort).
Week 2 · Jun 8–14
Hashing Graphs
Hashing (chaining, open addressing, load factor). Graph representations, BFS, DFS, applications (topological sort, SCC, bipartite check), Dijkstra, Bellman-Ford, Floyd-Warshall, Prim's, Kruskal's (MST).
Week 3 · Jun 15–21
Sorting Searching Recurrences
All sorting algorithms (time/space complexity), stability. Binary search variants. Recurrence relations (substitution, iteration, Master Theorem). Divide & Conquer (Merge Sort, Quick Sort, Strassen's).
Week 4 · Jun 22–30
DP Greedy Complexity
Dynamic programming (LCS, LIS, 0/1 Knapsack, matrix chain, DP on trees). Greedy (activity selection, Huffman coding, fractional knapsack). P vs NP, NP-hard, NP-complete problems.
🎯 June Target: DS + Algorithms complete · 100+ PYQs solved · Mock test on these 2 subjects
July 2026
PHASE 3 · OPERATING SYSTEMS
Week 1 · Jul 1–7
Processes & Threads CPU Scheduling
Process vs Thread, PCB, context switching, process states. CPU scheduling: FCFS, SJF, Priority, Round Robin, MLFQ. Scheduling criteria: CPU utilization, throughput, turnaround, waiting time. Gantt charts.
Week 2 · Jul 8–14
Synchronization Deadlocks
Critical section, Peterson's solution, Mutex, Semaphores (binary/counting), Monitors. Classic problems: Dining Philosophers, Producer-Consumer, Readers-Writers. Deadlock: conditions, resource allocation graph, Banker's algorithm, detection & recovery.
Week 3 · Jul 15–21
Memory Management
Logical vs physical address, contiguous allocation, fragmentation, paging (page tables, multi-level paging, inverted page table), TLB, segmentation, segmentation with paging, virtual memory, demand paging, page replacement algorithms (FIFO, LRU, Optimal), thrashing.
Week 4 · Jul 22–31
File Systems I/O OS PYQs
File system structure, directory structure, allocation methods (contiguous, linked, indexed), free space management. I/O management, disk scheduling (FCFS, SSTF, SCAN, C-SCAN). Solve all OS PYQs from 2015–2024.
🎯 July Target: Complete OS · 80+ OS PYQs · Mini mock (Maths + DS + Algo + OS)
August 2026
PHASE 4 · DBMS + COMPUTER NETWORKS
Week 1 · Aug 1–10
DBMS Foundations
Relational model, ER diagrams → relation mapping, SQL (DDL, DML, DCL, TCL), views, stored procedures, triggers, subqueries, joins (inner/outer/natural/cross), aggregation functions.
Week 2 · Aug 11–17
Normalization Transactions
Functional dependencies, Armstrong's axioms, closure of attributes, canonical cover. 1NF, 2NF, 3NF, BCNF, 4NF (lossless decomposition, dependency preservation). ACID properties, serializability, conflict/view serializability, concurrency control (2PL, timestamp protocols), recovery (ARIES).
Week 3 · Aug 18–24
Indexing Query Processing DBMS PYQs
B-trees, B+ trees (insertion, deletion, search), dense vs sparse index, clustered vs unclustered. Query processing: selection, projection, joins. Query optimization: cost estimation, join ordering. Solve 60+ DBMS GATE PYQs.
Week 4 · Aug 25–31
Computer Networks Start
OSI model (all 7 layers, protocols), TCP/IP model, IP addressing (IPv4, IPv6), subnetting, CIDR, NAT. Routing algorithms: Dijkstra (link-state), Bellman-Ford (distance vector), OSPF, RIP, BGP. Switching: circuit, packet, message switching.
🎯 August Target: DBMS + CN foundation complete · 80+ combined PYQs · Full mock (4 subjects)
September 2026
PHASE 5 · CN + COA + DIGITAL LOGIC
Week 1 · Sep 1–7
Computer Networks (cont.)
Data Link Layer: framing, error detection/correction (Hamming code, CRC), flow control, sliding window protocols (Go-Back-N, Selective Repeat), MAC protocols (CSMA/CD, CSMA/CA), Ethernet, 802.11. Transport Layer: TCP vs UDP, TCP connection (3-way handshake, congestion control).
Week 2 · Sep 8–14
Application Layer CN PYQs
HTTP/HTTPS, DNS, SMTP, FTP, DHCP, ARP, ICMP. Cryptography basics (symmetric, asymmetric, RSA). Solve all CN PYQs from GATE 2015–2024.
Week 3 · Sep 15–21
Digital Logic COA Basics
Boolean algebra, K-Maps (2/3/4 variable), combinational circuits (adder, subtractor, MUX, DeMUX, encoder, decoder), sequential circuits (flip-flops: SR, D, JK, T), registers, counters. Number systems, signed/unsigned representation, 2's complement arithmetic.
Week 4 · Sep 22–30
Computer Architecture
Instruction set architecture, RISC vs CISC, addressing modes. Pipelining: stages, hazards (structural, data, control), forwarding, stalling, branch prediction. Cache memory: direct mapped, set-associative, fully associative; replacement policies; cache performance. Memory hierarchy: SRAM, DRAM, virtual memory. I/O organization.
🎯 September Target: CN + DL + COA done · Full mock (6 subjects) · Score analysis
October 2026
PHASE 6 · TOC + COMPILER DESIGN + FULL REVISION ROUND 1
Week 1 · Oct 1–10
Theory of Computation
DFA/NFA (construction, equivalence, minimization), Regular expressions, Regular languages, Pumping Lemma (regular), Context-Free Grammars (derivation, parse trees, ambiguity), Pushdown Automata, Turing Machines (variants), Decidability and Undecidability, Halting problem, Rice's theorem.
Week 2 · Oct 11–17
Compiler Design
Compiler phases. Lexical analysis (tokens, DFA, LEX). Parsing: LL(1) grammar, FIRST/FOLLOW sets, LL(1) parsing table; LR parsing (SLR, LALR, CLR), shift-reduce conflicts. Semantic analysis (syntax-directed translation, attribute grammars). Intermediate code generation (3-address code, TAC). Code optimization (constant folding, dead code elimination, loop optimization). Code generation.
Week 3 · Oct 18–24
Revision Round 1A
Revise Engineering Maths (Discrete Math + LA + Probability) + Data Structures + Algorithms. Create final formula sheets. Solve 30 mixed PYQs from these subjects.
Week 4 · Oct 25–31
Revision Round 1B
Revise OS + DBMS + Computer Networks. Solve 30 mixed PYQs. Identify weakest topics across all subjects. Start building personal error log.
🎯 October Target: All 10 subjects covered · 250+ total PYQs · 2 full mock tests · Weak area list ready
